# Calculator UI

A minimal static calculator web app (HTML/CSS/JS) supporting basic math operations (+, -, ×, ÷), percent, clear, and delete.

Run locally (no install required):

```bash
# serve with npx (recommended)
npx http-server ./ -p 8080

# or install http-server globally and run
# npm i -g http-server
# http-server ./ -p 8080
```

Open http://localhost:8080 in your browser and open `index.html`.
